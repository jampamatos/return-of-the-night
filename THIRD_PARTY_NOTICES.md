# Third-Party Notices

## Cities Without Number

Return of the Night is an independent, unofficial game setting, table hack, and digital-book project that uses **Cities Without Number** as its base game engine.

Cities Without Number is published by Sine Nomine Publishing. Return of the Night is not official, affiliated with, endorsed by, approved by, or produced by Sine Nomine Publishing.

Where this project uses Cities Without Number game mechanics, it relies only on material covered by the [Cities Without Number System Reference Document](https://d1vzi28wh99zvq.cloudfront.net/pdf_previews/452790-sample.pdf). The SRD describes its covered material as released under CC0 and explains the limits of that release.

The project does not reproduce Cities Without Number text, setting material, characters, organizations, locations, events, artwork, or other creative material that is outside that SRD. Return of the Night's explanations, setting, adaptations, factions, terminology, scenarios, tables, and other creative content must be written originally unless a separate, documented permission applies.

This notice is a project policy and attribution statement, not legal advice. Contributors who are unsure whether material is covered by the SRD must not add it until its licensing status has been confirmed.
