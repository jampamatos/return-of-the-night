# Code of Conduct

## Purpose

This project aims to be a serious, sustainable, and welcoming open-source space.

We want contributors, maintainers, and community members to be able to participate without harassment, hostility, or exclusion.

This Code of Conduct defines the minimum behavior expected in project spaces and how maintainers may respond when that standard is not met.

## Scope

This Code of Conduct applies to:

- GitHub issues, pull requests, discussions, comments, and reviews
- project documentation and contribution spaces
- direct interactions that are clearly connected to this repository or conducted in a project capacity

## Expected behavior

Participants are expected to:

- be respectful, clear, and constructive
- assume good faith while still discussing technical disagreements directly
- give feedback about ideas, code, and decisions without attacking people
- respect differences in experience level, background, identity, and communication style
- help keep the project welcoming for new and existing contributors
- accept moderation decisions made to protect the health of the project

## Unacceptable behavior

- harassment, intimidation, or discrimination of any kind
- insults, personal attacks, or demeaning language
- bad-faith argumentation, trolling, or deliberately inflammatory behavior
- sexualized language or unwanted sexual attention
- publishing or threatening to publish private information without consent
- repeated disruption of project discussions after moderation requests
- any conduct that a reasonable maintainer would consider hostile, unsafe, or exclusionary

## Reporting

If you experience or witness unacceptable behavior, report it to the repository maintainer privately via [email](mailto:jp.coutm@gmail.com).

When reporting, include:

- what happened
- where it happened
- who was involved
- links, screenshots, or other supporting context if available

Good-faith reports will be reviewed as promptly and discreetly as reasonably possible.

## Enforcement

Maintainers may take any action they judge appropriate for protecting the project and its participants, including:

- requesting a change in behavior
- moderating, editing, or removing comments or contributions
- temporarily locking conversations
- limiting participation
- banning a person from project spaces

## Enforcement principles

When possible, maintainers should aim to be:

- fair
- consistent
- proportionate to the behavior
- focused on protecting people and the project rather than punishing for its own sake

## No retaliation

Retaliation against anyone who makes a good-faith report or participates in an investigation is itself a violation of this Code of Conduct.
