## Placeholders de estruturas de campanha

Este capítulo reserva um conjunto estruturado de formatos de campanha originais. Cada formato final deve declarar uma pressão inicial, uma aposta humana, um caminho de escalada e uma pergunta deixada aberta para o jogo.

:::columns
:::column

### Estrutura imediata

Reserve uma primeira missão contida que ensine o cenário pela ação.
:::
:::column

### Estrutura longa

Reserve uma questão de campanha capaz de mudar o que as pessoas acreditam sobre o mundo.
:::
:::
