## Campaign frame placeholders

This chapter reserves a structured set of original campaign frames. Each final frame should state a starting pressure, a human stake, an escalation path, and a question left open for play.

:::columns
:::column

### Immediate frame

Reserve a contained first mission that teaches the setting through action.
:::
:::column

### Long frame

Reserve a campaign question that can change what people believe about the world.
:::
:::
